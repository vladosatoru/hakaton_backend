# ЦОДД Смоленской области - Backend API

Цифровая веб-платформа для Центра организации дорожного движения Смоленской области.

## 🚀 Описание проекта

Система предназначена для управления данными ЦОДД, включая:
- Статистику штрафов и эвакуации
- Реестр светофоров
- Заявки на эвакуацию
- Аналитику и отчетность
- Систему ролей и доступа
- Импорт/экспорт данных

## 🛠 Технологический стек

- **Backend**: NestJS + TypeScript
- **База данных**: PostgreSQL + Prisma ORM
- **Аутентификация**: JWT
- **Документация**: Swagger/OpenAPI
- **Файлы**: Multer, XLSX, CSV
- **Валидация**: class-validator

## 📋 Требования

- Node.js 18+
- PostgreSQL 14+
- npm или yarn

## 🔧 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd backend
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка окружения
Создайте файл `.env` в корне проекта:
```env
DATABASE_URL="postgresql://username:password@localhost:5432/hakaton"
JWT_SECRET="your-jwt-secret-key"
PORT=4200
```

### 4. Настройка базы данных
```bash
# Применение миграций
npx prisma migrate dev

# Генерация Prisma Client
npx prisma generate

# Заполнение тестовыми данными
npx ts-node seeder/seed.ts
```

### 5. Запуск сервера
```bash
# Режим разработки
npm run start:dev

# Продакшн
npm run build
npm run start:prod
```

Сервер будет доступен по адресу: `http://localhost:4200`

## 📚 API Документация

Swagger документация доступна по адресу: `http://localhost:4200/api/docs`

### Основные эндпоинты:

#### Аутентификация
- `POST /api/auth/register` - Регистрация пользователя
- `POST /api/auth/login` - Вход в систему
- `GET /api/auth/profile` - Профиль пользователя

#### Статистика штрафов
- `GET /api/fine-statistics` - Получение статистики (публичный доступ)
- `POST /api/fine-statistics` - Создание записи (админ/редактор)
- `GET /api/fine-statistics/analytics` - Аналитика
- `GET /api/fine-statistics/compare/:year1/:year2` - Сравнение по годам

#### Заявки на эвакуацию
- `POST /api/evacuation-requests` - Подача заявки (публичный доступ)
- `GET /api/evacuation-requests` - Список заявок (админ/редактор)
- `PATCH /api/evacuation-requests/:id/status` - Изменение статуса

#### Реестр светофоров
- `GET /api/traffic-light-registry/public` - Публичный реестр
- `POST /api/traffic-light-registry` - Добавление светофора (админ/редактор)
- `GET /api/traffic-light-registry/statistics` - Статистика

#### Импорт/Экспорт
- `POST /api/import-export/import` - Импорт данных (админ)
- `POST /api/import-export/export` - Экспорт данных (админ/редактор)
- `POST /api/import-export/analyze-file` - Анализ файла для импорта

## 👥 Система ролей

## 📊 Структура базы данных

### Основные таблицы:

#### FineStatistics (Статистика штрафов)
- `date` - Дата
- `year` - Год
- `violationsDetected` - Количество нарушений
- `decreesIssued` - Количество постановлений
- `finesImposed` - Сумма наложенных штрафов
- `finesCollected` - Сумма взысканных штрафов

#### EvacuationStatistics (Статистика эвакуации)
- `date` - Дата
- `year` - Год
- `towTrucksOnLine` - Эвакуаторов на линии
- `callouts` - Количество выездов
- `evacuationsCount` - Количество эвакуаций
- `impoundLotRevenue` - Доходы штрафстоянки

#### TrafficLightRegistry (Реестр светофоров)
- `registryNumber` - Номер в реестре
- `address` - Адрес
- `lightType` - Тип светофора
- `installYear` - Год установки
- `status` - Статус (активен/неактивен/ремонт)

#### EvacuationRequest (Заявки на эвакуацию)
- `address` - Адрес
- `vehicleType` - Тип транспорта
- `contactName` - Имя заявителя
- `contactPhone` - Телефон
- `estimatedCost` - Расчетная стоимость
- `status` - Статус заявки
